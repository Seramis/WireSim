# Z80

Zilog Z80 CPU, documented instruction set only. Source of truth: Z80 CPU User Manual (UM008011-0816, `docs/Zilog Z80.pdf`; read w/ `pdftotext -layout`). Timing diagrams (Figures 4-15, PDF pages 22-31) are images: render w/ `pdftoppm`.

## Pinout reference

Active-low signals carry `Not` prefix. Active-low inputs read inactive while nothing drives them.

| Pin | Dir | Meaning |
| --- | --- | --- |
| `CLK` | in | Single-phase clock. Everything happens on its edges (stable trigger). |
| `A` (16) | out, tri-state | Address bus. |
| `D` (8) | in/out, tri-state | Data bus. CPU drives it only in write cycles. |
| `NotM1` | out | Opcode fetch and interrupt acknowledge cycles. |
| `NotMREQ` | out, tri-state | Memory request. |
| `NotIORQ` | out, tri-state | I/O request, also low in interrupt acknowledge cycle. |
| `NotRD` | out, tri-state | Read strobe. Not asserted in interrupt acknowledge cycle or refresh half of M1. |
| `NotWR` | out, tri-state | Write strobe. |
| `NotRFSH` | out, tri-state | Refresh, `A` = `I:R`. |
| `NotHALT` | out | Low while halted. |
| `NotWAIT` | in | Wait request. |
| `NotINT` | in | Maskable interrupt request, level sensitive. |
| `NotNMI` | in | Non-maskable interrupt request, latched on falling edge. |
| `NotRESET` | in | Reset. |
| `NotBUSREQ` | in | Bus request. |
| `NotBUSACK` | out | Bus acknowledge. |

## Internal state reference

`DumpRegisters()` (`dumpregs`, `expect reg.<name>`):

| Name | Meaning |
| --- | --- |
| `PC` `SP` `IX` `IY` | 16-bit registers. `PC` = address of next opcode fetch. |
| `A` `F` `B` `C` `D` `E` `H` `L` | Main register set. |
| `A2` `F2` `B2` `C2` `D2` `E2` `H2` `L2` | Alternate set (swapped by `EXX` and `EX AF,AF'`). |
| `I` `R` | Interrupt vector page, refresh counter. |
| `IFF1` `IFF2` `IM` | Interrupt enable flip-flops (0/1), interrupt mode (0-2). |
| `FS` `FZ` `FH` `FPV` `FN` `FC` | Documented flag bits of `F` as 0/1, so test checks only flags the manual defines. |

`F` bit 7..0 = S Z - H - P/V N C. Bits 3 and 5 are "not used" in manual, not modeled: instruction updating `F` writes them 0, instruction not touching `F` leaves them, `POP AF` and `EX AF,AF'` move them like any bit.

Power-on: `A` = `F` = `FFh`, `SP` = `FFFFh`, rest 0. Reset (below) leaves them.

## Behavior

### Structure

`Z80` (`Z80.hpp`) = `Sim::Device` wrapper: copies pins into `Z80Impl::Cpu::pins`, calls `Cpu::Next()`, drives outputs. Only `CLK` edges and `NotNMI` (stable triggers) call it.

`Cpu` (`Z80Impl.cpp`) = T-state engine. Each instruction in `Z80Exec.cpp` is a C++23 coroutine that `co_await`s one bus cycle at a time (`Fetch`, `Read`, `Write`, `In`, `Out`, `Idle`, `IntAck`, `Boundary`) w/ manual's M-cycle lengths; engine runs cycle edge by edge, resumes instruction when cycle's data is available. Coroutine frames live in 4 KiB arena inside CPU, so execution never allocates. Opcodes decoded by field (x = op[7:6], y = op[5:3], z = op[2:0], p = y[2:1], q = y[0]).

### Bus profile

One `CLK` period = one T-state: rising edge, then falling edge. Outputs written on an edge are visible one sim cycle later, so script uses `step 2` after every edge. Cycle macro starts at rising edge beginning T1, ends after falling edge of last T-state.

Output changes by cycle (R = rising edge, F = falling edge; WAIT sampled on F edge named, low level adds one wait state, sampled again on its own F edge):

| Cycle | T-states | Edges |
| --- | --- | --- |
| Opcode fetch (M1) | 4, or 5 / 6 | T1 R: `A`=PC, `NotM1` low. T1 F: `NotMREQ`, `NotRD` low. T2 F: WAIT. T3 R: `D` sampled, `NotMREQ`/`NotRD`/`NotM1` high, `NotRFSH` low, `A`=`I:R`. T3 F: `NotMREQ` low. T4 F: `NotMREQ` high. Extra T-states: `NotRFSH` high from first extra T-state's R, no strobe active. |
| Memory read | 3 | T1 R: `A`. T1 F: `NotMREQ`, `NotRD` low. T2 F: WAIT. T3 F: `D` sampled, both high. |
| Memory write | 3 | T1 R: `A`. T1 F: `NotMREQ` low, `D` driven. T2 F: `NotWR` low, WAIT. T3 F: `NotWR`, `NotMREQ` high. `D` released next R. |
| I/O read | 4 (T1 T2 TW T3) | T1 R: `A` = port address. T2 R: `NotIORQ`, `NotRD` low. TW F: WAIT (automatic wait state; no sample on T2). T3 F: `D` sampled, both high. |
| I/O write | 4 | T1 F: `D` driven. T2 R: `NotIORQ`, `NotWR` low. TW F: WAIT. T3 F: both high. `D` released next R. |
| Interrupt acknowledge | 6 (T1 T2 TW TW T3 T4), plus instruction's extension | T1 R: `A`=PC, `NotM1` low. TW1 F: `NotIORQ` low. TW2 F: WAIT. T3 R: `D` sampled (vector), `NotIORQ`/`NotM1` high, `NotRFSH` low, `A`=`I:R`. T3 F: `NotMREQ` low. T4 F: `NotMREQ` high. `NotRD` stays high. |
| Internal | n | No strobe active; `A` and `D` undefined. |

M-cycle lengths of every instruction = manual's (rows in `Z80.coverage.md`). Where length exceeds bus part (`MR` 4/5, `MW` 5, M1 5/6), bus transaction comes first, extra T-states follow. Indexed addressing adds internal 5 T-state cycle after displacement read, except `LD (IX+d),n` (its `n` read is 5 T-states) and `DD CB d op` (its `op` read, plain memory read not M1, is 5 T-states).

Registers change once the data deciding them is latched; every effect of an instruction is visible after falling edge of last T-state of its last M-cycle.

### R, I and the refresh address

`R` counts every M1 cycle: opcode and prefix fetches, interrupt acknowledge, NMI response, each halted fetch. Bit 7 changed only by `LD R,A`. Refresh address = `I` in `A15-A8`, `R` as before that cycle's increment in `A7-A0`. Opcode byte of `DD CB d op` is a memory read, doesn't count.

### Reset

`NotRESET` low, sampled on rising edge, aborts running cycle: `A` and `D` float, `NotMREQ` `NotIORQ` `NotRD` `NotWR` `NotRFSH` `NotM1` `NotHALT` `NotBUSACK` driven high. `PC`, `I`, `R`, `IFF1`, `IFF2`, `IM` cleared; other registers keep values. First rising edge sampling `NotRESET` high = T1 of M1 cycle at 0000h. Manual's three-clock minimum not enforced: any sampled low resets.

### WAIT

Sampled as in table. Internal T-states, T1 and T3 of memory cycles ignore it.

### Bus request

`NotBUSREQ` sampled every rising edge, honoured at end of every M-cycle (sample on rising edge of its last T-state). Next rising edge: `A`, `D`, `NotMREQ` `NotIORQ` `NotRD` `NotWR` `NotRFSH` float, `NotBUSACK` goes low. First rising edge after first granted T-state sampling `NotBUSREQ` high is followed, on its falling edge, by `NotBUSACK` high; bus driven again next rising edge, starting interrupted instruction's next cycle. Bus request at instruction boundary blocks both interrupts for that boundary: still-pending interrupt taken at end of next instruction.

### HALT

`HALT` sets halted state; `NotHALT` goes low on falling edge of T4 of its M1. While halted CPU repeats M1 at address of instruction after `HALT`; byte read ignored (NOP executed), `PC` doesn't move, `R` counts. Pending NMI, or INT w/ `IFF1` set, sampled on rising edge of T4 ends halt: `NotHALT` rises on that cycle's falling edge, interrupt cycle follows. `HALT` executed w/ interrupt already acceptable is left at once, `NotHALT` stays high.

### Interrupts

NMI latched on any falling edge of `NotNMI`. NMI and INT sampled on rising edge of last T-state of every instruction (and each halted fetch), taken at end of that instruction. Nothing taken between `DD`/`FD`/`ED`/`CB` prefix and its opcode. NMI beats INT; INT needs `IFF1`, level sensitive.

- **NMI**: M1 cycle (5 T-states, byte read ignored, `PC` not advanced), push `PC`, `PC` = 0066h, `IFF2` = `IFF1`, `IFF1` = 0. 11 T-states.
- **INT mode 0**: acknowledge cycle (above, `IFF1` = `IFF2` = 0); byte on `D` = first byte of instruction executed w/ its first M1 replaced by acknowledge cycle; further bytes are ordinary memory reads at `PC`, `PC` not advanced for first byte. M1 is two T-states longer than instruction's own.
- **INT mode 1**: acknowledge (byte ignored), push `PC`, `PC` = 0038h. 13 T-states.
- **INT mode 2**: acknowledge, byte on `D` = low address byte, push `PC`, read vector at `I:byte` (bit 0 not forced 0), `PC` = vector. 19 T-states.
- `EI` sets `IFF1` and `IFF2`; INT not taken at end of `EI` itself, nor, if next instruction is another `EI`, until after first instruction that isn't one. `DI` clears both flip-flops immediately.
- `RETN` copies `IFF2` to `IFF1`. `RETI` leaves both alone.
- `LD A,I` and `LD A,R` set P/V from `IFF2`, but 0 if interrupt (NMI or INT) taken at end of that instruction.
- Block instructions (`LDIR` ... `OTDR`) repeat by taking `PC` back 2 after each iteration, so interrupt is taken between iterations and returns to block instruction.

## Added features

- `FS` `FZ` `FH` `FPV` `FN` `FC` in `DumpRegisters()`: documented flag bits, so tests can ignore flags manual calls unknown.

## Limitations

Deviations from, and gaps in, manual. Each covered by test stating chosen behavior.

- **Not modeled**: flag bits 3 and 5; undocumented index half registers (`IXH`, `IXL`, `IYH`, `IYL`); `MEMPTR` register; clock stop (power-down); DMA/refresh interplay of long bus grants.
- **Encodings manual doesn't define are no-ops of length they'd have**: every `ED xx` not in manual (two M1 cycles, 8 T-states, no effect, no I/O cycle for `ED 71`); `CB 30`-`CB 37` (`SLL`); `DD`/`FD` before opcode w/ no indexed form (4 T-state prefix, then opcode runs unindexed, so `DD 7C` is `LD A,H`); chain of `DD`/`FD` prefixes (each one M1, last selects register). `DD CB d op` and `FD CB d op` w/ `op[2:0]` other than 6 perform documented (IX+d)/(IY+d) operation, ignore register field.
- **"Unknown" flags** keep previous value: S and P/V after `BIT`; S, H and P/V after `INI` `IND` `OUTI` `OUTD` and repeating forms.
- **Instruction timing**: manual lists `INI` `IND` `INIR` `INDR` as (4, 5, 3, 4) but describes port read before memory write; model does port read in 4 T-state cycle, then memory write in 3 T-state cycle (4, 5, 4, 3). Total T-states match manual.
- **Where manual is silent**: placement of idle T-states inside extended M-cycle (see bus profile); `A` and `D` undefined during internal T-states; `NotRFSH` going high at first extra T-state of extended M1; refresh address using `R` before its increment, `LD A,R` reading `R` after its own two increments; H flag after `DAA` and `DAA` w/ flag combinations outside manual's table (same correction arithmetic applied); registers after reset other than `PC`, `I`, `R`, interrupt state; bus grant length when `NotBUSREQ` released early (at least 1.5 T-states).
- **Manual errata worked around**: `AND`, `SBC` P/V text says "reset if overflow" (parity and overflow respectively); worked examples for `ADD IX,BC` (`0333h + 5555h`), `ADD IY,BC` (`0333h + 0555h`) give `8888h`, `RRCA` shows `1001 1000` for `0001 0001`; `BIT b,(HL)` and `BIT b,(IY+d)` say "H is reset" (H is set); cycle table of `RES r` says four M-cycles, of `JR NC` (not taken) seven; `CALL cc` lists `C` as `Z`.
